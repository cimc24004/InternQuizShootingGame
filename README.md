# Quiz Survivors

10日間のインターンで制作した、クイズと2Dサバイバルシューティングを組み合わせたブラウザゲームです。敵を避けながら制限時間まで生き残ることを目指します。プレイ中に出題されるクイズに正解すると、武器の数や弾の性能が強化されます。

## 遊び方

1. [`ミニプロゲーム/index.html`](ミニプロゲーム/index.html) をブラウザで開き、**GameStart** を押します。外部CDNからライブラリを読み込むため、インターネット接続が必要です。
2. **W / A / S / D** で移動します。弾はマウスカーソルの方向に自動で発射されます。
3. クイズに答えてプレイヤーを強化し、制限時間まで生き残ります。

## 実装の見どころ

ゲームエンジンは使わず、Unityの `Start` / `Update` に着想を得て、JavaScriptのクラスでゲームの土台を作りました。毎フレームの処理、キー入力、ベクトル演算、当たり判定を共通化し、その上にプレイヤー・敵・弾・クイズの処理を組み立てています。

| ソースコード | 役割 |
| --- | --- |
| [main.js](ミニプロゲーム/main.js) / [GameObject.js](ミニプロゲーム/GameObject.js) | `requestAnimationFrame` を使ったゲームループと、各オブジェクトの初期化・更新 |
| [Collider.js](ミニプロゲーム/Collider.js) | 矩形が横・縦の両方で重なるかを調べる当たり判定 |
| [GameManager.js](ミニプロゲーム/GameManager.js) | 敵の出現、残り時間、クイズの出題タイミングの管理 |
| [QuizManager.js](ミニプロゲーム/QuizManager.js) / [player.js](ミニプロゲーム/player.js) | クイズの正誤判定・解説表示と、正解に応じたプレイヤー強化 |

## 使用技術

HTML / CSS / JavaScript（ES6のクラス構文） / jQuery
